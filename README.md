# Трекер спільних витрат (Shared Expense Tracker — Splitwise CLI)
Програмний комплекс призначений для спрощення та автоматизації фінансового обліку, ведення списку боргових зобов'язань та розподілу витрат всередині визначеної групи людей (наприклад, між сусідами по кімнаті, колегами чи під час спільних подорожей). Проєкт реалізовано в межах курсової роботи з дисципліни "Об'єктно-орієнтоване програмування".

##  Основний функціонал
* Реєстрація учасників групи: Додавання об'єктів користувачів User (dataclass) з валідацією полів.
* Поліморфна логіка розподілу: Підтримка двох різних алгоритмів підрахунку часток:
  * Ділення порівну між обраними учасниками (EqualSplit).
  * Ділення за відсотковими частками з сумарною валідацією 100% (PercentageSplit).
* Розрахунок балансів (Ядро взаєморозрахунків): Метод автоматично агрегує всі записи й виводить фінальний баланс для кожного учасника (позитивний — скільки йому винні, негативний — скільки він винен групі).
* Персистентність даних: Стан групи, список витрат та історія балансів повністю серіалізуються у бінарний формат за допомогою модуля pickle.
* Звітність: Можливість швидкого експорту поточної таблиці взаєморозрахунків у формат csv.
* Стійкий CLI-інтерфейс: Консольне меню працює на базі оператора match/case та захищене від некоректного введення користувача (Fault Tolerance) завдяки централізованому перехопленню помилок.

##  Вимоги до середовища
Для запуску ядра системи необхідне таке програмне забезпечення:
* Python версії 3.10 або новішої.
* Вбудований менеджер пакунків pip (для встановлення у режимі розробки).
